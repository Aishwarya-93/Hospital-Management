# ADP Hospital Management System - Bootstrap Experiment 3

This project was upgraded using Bootstrap 5.3.3 and Bootstrap Icons.

## Experiment requirements covered
- Responsive `.container` and `.container-fluid` concepts
- Bootstrap responsive grid using `.row`, `.col-*`, `.col-sm-*`, and `.col-md-*`
- Responsive navbar with dropdown navigation
- Search input groups with Bootstrap Icons
- Circular image using `.rounded-circle` and responsive image helpers
- Dismissible alerts using `.alert` and `.alert-dismissible`
- Pagination using `.pagination`, `.page-item`, and `.page-link`
- Bootstrap buttons, cards, tables, forms, spacing and utility classes
- Custom CSS for a cleaner hospital-themed interface

## Run
Open `index.html` or `home.html` in a browser. An internet connection is required for the Bootstrap CDN.
